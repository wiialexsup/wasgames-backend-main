# wasgames-backend
бэк для магазина настолок
# как запустить проект?
нужно скачать postgresql (если нет), создать там базу данных wasgames, добавить пользователя wasgames_user и дать ему пароль 'password', далее можно уже зайти в VS code, и просто прописать команду в терминал: mvn spring-boot:run. всё, у тебя получилось!
